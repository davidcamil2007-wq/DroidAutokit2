# AutoDroid Car

Dois apps:
- kit/   -> "AutoDroid Kit": instalar NO KIT. Tela principal estilo Android Auto + notificações à direita.
- phone/ -> "AutoDroid Celular": instalar NO CELULAR. Só envia as notificações ao kit (sem acessibilidade,
            sem sobreposição, sem captura de tela).

Fluxo: ligar o hotspot do celular -> conectar o kit nele -> abrir o AutoDroid Kit.
Notificações do celular (redes sociais, mensagens, ligações, alarmes) aparecem à direita no kit,
com respostas rápidas que o celular envia pelo app original.
